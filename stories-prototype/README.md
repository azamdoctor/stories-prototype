# Сторисы — прототип CRM

Прототип раздела **«Сторисы»** для CRM «Рабочие руки»: редактор, аналитика, шаблоны. Vite + React 18 + Tailwind CSS, без бэкенда — данные в памяти.

## Что в прототипе

**Редактор сторис.** Слева — sticky-превью на телефоне с переключателем «Главный экран / Сторис открыта», справа — карточки настроек. Сверху — двухрядный «Быстрый переход» по секциям. Заполняется: обложка и контент (видео до 60 сек / фото), заголовок и описание с тулбаром форматирования и эмодзи, до 5 ссылок (только внутренние `app://`, внешние запрещены), кнопка «Связаться» с мультиканалами (звонок, WhatsApp, Telegram, Макс, своя ссылка), реакции (1–4 эмодзи), доплата от РР, флаг «Срочная сторис» с пульсирующей анимацией, авто-снятие по таймеру или битой ссылке, A/B-тест с двумя обложками. Публикация заменена на **отправку на верификацию** — после клика появляется плашка «Ваша история отправлена на верификацию».

**Таргетинг.** Быстрые сегменты (включая «Был в приложении» с выбором периода 24ч–90д), города с учётом области, мульти-выбор партнёров (ООО/ИП), объект/точка, профессия. Развёрнутые ERP-фильтры — гражданство, пол, возрастной диапазон, метро, тип документа, статус самозанятости, выполненные задания за период, минимальный рейтинг (слайдер 0–10), запрет оплаты, верификация платёжных данных, чёрный список партнёра, оператор обработки и доп. условия (онлайн / не забанены / вахта / штраф). Альтернатива — загрузка списка из Excel с матчингом и расчётным охватом.

**Верификация сторис.** Отдельный раздел модерации с очередью на проверку (превью, автор, охват, мета-инфо) и историей решений. Кнопки **«Одобрить»** и **«Отклонить»** — при отказе выбираются типовые причины (низкое качество, орфография, юр-риски, дубликат и др.) и оставляется комментарий. В сайдбаре и action bar — бейдж с количеством в очереди.

**Аналитика.** Переключатель **«Общая статистика / По конкретной сторис»**. 6 KPI: просмотры, **уникальные просмотры** (каждый исполнитель учитывается один раз), клики, записи, выходы на задание, конверсия. Карточка с детализацией уникальных (повторные, среднее на исполнителя, доля). Воронка от просмотра до выхода, кривая досмотра видео или медиана для фото, heatmap CTR по часу/дню, бары по городам с разрезом «город+область», динамика по дням, реакции, сравнительная таблица всех сторис с колонкой «Уникальные» и ROI, таблица исполнителей с колонками «1-й просмотр» / «Всего открытий», фильтрами (Уникальные / Повторные / Не увидели / Поставили реакцию) и Excel-выгрузкой. В режиме общей статистики — топ сторис по уникальным просмотрам.

**Список сторис.** Таблица со статусами; чипы фильтров **Все / Активные / Запланированные / Черновики / Архив** со счётчиками. Отдельные колонки **«Дата публикации»** и **«Дата снятия с публикации»** — для активных и запланированных видно одновременно когда сторис вышла и когда автоматически снимется; для архивных — дата исходной публикации и дата ручного архивирования. Иконки действий рабочие с мгновенными tooltip-подсказками: редактировать (открывает редактор с восстановленными данными), дублировать (создаёт копию в черновиках), архивировать (с подтверждением), восстановить из архива, **удалить безвозвратно** (отдельная модалка с предупреждением, что статистика не сохранится). Раскрывающаяся секция «Ряд кружочков и управление порядком» — перетаскивание/закрепление позиций как на главном экране приложения.

**Шаблоны.** Галерея готовых конструкций — текст, кнопки, реакции, таргетинг. Категории: «Срочные задания», «Акции», «Онбординг». При создании сторис можно: выбрать шаблон, начать с нуля или **продолжить заполнение последнего черновика** — в модалке появляется отдельная карточка с превью обложки, прогрессом заполнения и временем сохранения.

**Подробное описание аналитики** — в [docs/analytics_panel_overview.md](docs/analytics_panel_overview.md).

## Запуск

Нужен **Node.js 18+** ([nodejs.org](https://nodejs.org/)).

```bash
npm install
npm run dev
```

Откроется `http://localhost:5173`.

## Стек

- **React 18** — UI
- **Vite 5** — сборщик и dev-сервер
- **Tailwind CSS 3** — стили
- **lucide-react** — иконки
- **recharts** — графики

## HTML-макет без сборки

В `docs/stories_editor_mockup.html` лежит standalone-версия с тем же CRM-фреймом (сайдбар, хедер, вкладки, редактор, аналитика на Chart.js). Открывается двойным кликом — Node.js не нужен. Полезно для быстрого показа дизайна без установки зависимостей.
